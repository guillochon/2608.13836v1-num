# Brenti tilde-R polynomial search

See [WRITEUP.md](WRITEUP.md) for the verification of Gaetz’s \(S_{14}\) example, exhaustive counts through \(S_9\), and [EMAIL.md](EMAIL.md) for a draft note to the author.

This source-only C++17/OpenMP program searches type-A Bruhat intervals for failures of log-concavity of the coefficient sequence of `Q_{u,v}` from Christian Gaetz, *A counterexample to a log-concavity conjecture of Brenti* (arXiv:2608.13836v1).

It implements symmetric groups only.  The paper's separate type-`H4` example is not represented by permutations and is deliberately not claimed to be implemented here.

## Build

```sh
make
```

A C++17 compiler with OpenMP support is required.  For a local Clang OpenMP installation, for example:

```sh
make CXX=clang++ OMP='-fopenmp'
```

## Verify the paper's S14 example

```sh
./brenti_search --verify-s14
```

The program independently computes the recurrence polynomial and checks Bruhat comparability, relative length 29, and the ascending-degree coefficient vector

```text
[0,0,0,0,0,1,11,123,425,695,630,333,101,16,1]
```

A successful run ends with `S14 verification: PASS`.

## Exhaustive search

```sh
OMP_NUM_THREADS=$(nproc) ./brenti_search --exhaustive 8 --out S8.cert --checkpoint S8.done
```

The outer upper permutation `v` is distributed with OpenMP.  For each `v`, the principal Bruhat ideal is generated by covering transpositions rather than by testing all `n!` candidates.  Pairs that share a right descent are skipped: the recurrence says they have the same `Q` as a strictly shorter pair, which is visited when the reduced upper element is processed.  The checkpoint is an append-only list of completed factoradic ranks of `v`.

The compact one-line encoding stores each value in four bits, so the supported range is `1 <= n <= 15`.

On a 16-thread 12th-gen Intel Core i5-12600K this finds:

- `S8`: 170,288,585 intervals, 0 violations, 22 seconds (confirms the paper).
- `S9`: 10,501,351,657 intervals, 0 violations, 27.3 minutes.

So any type-A counterexample has rank at least 10.  Directed search in `S10`–`S13` (all 2^14 patterns of the paper's pair, inversion-table mimics, 600k random reduced intervals per rank) found no violation; the paper's `S14` example is also pattern-minimal.

Certificate lines give `u`, `v`, relative length, ascending `Q` coefficients, and a failed inequality.  Coefficient additions are checked `uint64_t` additions; an overflow aborts the run rather than emitting an unsound certificate.

Relative length of the paper's S14 pair is 29 (not 28): `inv(v)-inv(u)=46-17`. Degree 14 of `Q` is consistent with either parity; the odd case is the one that occurs.

## Directed search

```sh
OMP_NUM_THREADS=$(nproc) ./brenti_search --hunt 400000 --out hunt.cert --seed 1
./brenti_search --flatten --out flatten.cert
./brenti_search --explore 4000 --out explore.cert
```

`--flatten` tests all value and position patterns of the S14 pair in `S_k` for `5<=k<=13`. `--explore` walks the Bruhat cover graph around that pair. `--hunt` combines those with inversion-table mimics and random intervals in `S_9` through `S_13`.

## Mathematics and recurrence convention

For a right descent `s` of `v`, the implemented recurrence is

```text
tildeR(u,v) = tildeR(us,vs)                       if us < u,
tildeR(u,v) = tildeR(us,vs) + q tildeR(u,vs)      if us > u.
```

It uses `tildeR(x,y)=0` whenever `x` is not below `y` in Bruhat order, including recursive terms such as `tildeR(us,vs)` which need not be comparable in the second branch.  The nonzero base case is `tildeR(u,u)=1`.  Right multiplication by a simple reflection swaps adjacent positions in one-line notation.

Bruhat comparison uses the type-A northwest rank criterion: `u <= v` exactly when every prefix/value-bound count for `u` is at least the corresponding count for `v`.

If `d = length(v)-length(u)`, the powers in `tildeR(u,v)` have parity `d`.  Therefore the extracted polynomial is

```text
Q_i = [q^(2i)] tildeR(u,v)       if d is even,
Q_i = [q^(2i+1)] tildeR(u,v)     if d is odd.
```
